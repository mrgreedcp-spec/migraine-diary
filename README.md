# 偏头痛记录与用药沟通助手（MVP v1.0）

手机优先的本地 Web App。流程：填写基本情况 → 查看用药沟通卡 → 记录头痛和用药 → 录入量表结果 → 生成就诊摘要。

> 用于记录和就诊准备，具体诊断与用药请与医生确认。

## 在线使用

https://mrgreedcp-spec.github.io/migraine-diary/

用手机浏览器打开即可，可以“添加到主屏幕”。资料只保存在打开它的那个浏览器里，网站服务器不接收任何记录。

## 本地启动

需要 Node.js 18 及以上版本。

```bash
cd ~/Downloads/偏头痛记录助手_MVP
npm install
npm run dev        # 打开 http://127.0.0.1:5199
npm test           # 运行统计与校验规则测试
npm run build      # 生成静态文件到 dist/，可部署到任意静态托管
```

## 使用

1. 首次打开：先填基本情况。只有年龄预填 30，其余保持“未填写”。可以点“先跳过”。
2. 保存资料后直接进入「用药沟通卡」。卡片列出常见偏头痛药物类别，并按你的资料标出“建议与医生确认”的点。
3. 「记录」：选日期（默认今天，可补录，不可选未来），再选有／无／不确定头痛。有头痛时填疼痛分和活动影响。用药可加多条，没有头痛也能记。其余项放在“补充详情”。
4. 「汇总」：按自然月统计，并显示月历。数据不全时会提示。这里可以生成就诊摘要，也能打开用药沟通卡。
5. 「评估」：录入 MIDAS／HIT-6 总分，另有自编的“就诊前情况整理表”（不计分）。
6. 「我的」：编辑资料、下载或导入 JSON 备份、进入演示模式、清除数据、查看医学来源。

## 关于“填完基本信息后直接跳出推荐药品”

本版改为「用药沟通卡」，不输出个性化推荐，原因如下：
- PRD 第 1 节和验收标准 16 要求不生成个性化药物推荐、剂量或停药指令。
- 是否能用某类药，取决于医生的检查和判断。例如心血管病史与曲普坦类有关，备孕与托吡酯、丙戊酸、坎地沙坦有关。
- 卡片对所有人展示相同的药物类别和顺序，不排名、不写剂量。个人化部分只把用户填写的情况和通用注意事项对应起来，交给医生判断。
- 内容在 `src/medInfo.ts`，未经医学审核。正式上线前应由医生或药师审核，或换成经审核的药物知识库。

## 部署

仓库推送到 `main` 后，GitHub Actions（`.github/workflows/deploy.yml`）会依次安装依赖、运行测试、构建，然后发布到 GitHub Pages。测试不通过就不会发布。

- 手动重新发布：`gh workflow run deploy -R mrgreedcp-spec/migraine-diary`
- `index.html` 里设置了 `noindex`，搜索引擎不会收录。用药资料经过医学审核后，可以删掉这一行。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/rules.ts` | 统计口径、量表分级、预防治疗提示、用药频率问题（固定规则，可审查） |
| `src/validate.ts` | 每日记录校验、量表分数校验、JSON 导入校验 |
| `src/medInfo.ts` | 用药沟通卡内容和触发条件 |
| `src/summary.ts` | 就诊摘要，只使用用户输入和计算结果 |
| `src/storage.ts` | localStorage 读写，写入后回读校验 |
| `src/pages/*` | 各页面 |
| `tests/rules.test.ts` | 23 项规则测试 |

## 已知限制

- 数据只保存在当前浏览器，不跨设备同步。清理浏览器数据会丢失，请定期下载备份。
- MIDAS、HIT-6 只录入总分。完整问卷需取得授权和正规中文版本后再接入。mTOQ 只有说明，不计分。
- 不自动判断偏头痛类型，不诊断药物过度使用性头痛。
